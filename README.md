## О материалах

Собрано из шести архивов исходных репозиториев и архива `Netology-20261030T133309Z-1-001.zip`. Восемь документов Word преобразованы в Markdown; встроенные изображения извлечены и размещены в папках соответствующих работ. Иллюстрации включены в текст в порядке документа; отдельные страницы `IMAGES.md` содержат полный набор изображений.

Исходные Markdown-отчёты, скрипты и файлы учебных стендов сохранены. Тексты ответов и технические выводы не переписывались. Сведения и результаты проверок относятся ко времени выполнения учебных работ.

Материалы Word сохранены отдельными работами, в том числе при совпадении темы с исходными репозиториями. Курсовая МТУСИ по алгоритмам выделена отдельно, поскольку не относится к Нетологии. Документы `AD.docx` и `Win Hardering.docx` содержат преимущественно скриншоты; дополнительный текст к ним не придумывался.

## Загрузка на GitHub

Создайте пустой репозиторий `Homeworks-Netology`, откройте терминал в распакованной папке и выполните:

```bash
git init
git add .
git commit -m "Add Netology homeworks"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/Homeworks-Netology.git
git push -u origin main
```

Замените `YOUR_USERNAME` на свой логин GitHub.
